<h1 align="center">Translateer</h1>

<p align="center">
  Перевод выделенного текста между русским, английским и украинским одним сочетанием клавиш.
</p>

## Возможности

- Выделите текст в любой программе и нажмите **Ctrl+Alt+E** — появится перевод.
- Шесть направлений: русский ↔ английский, русский ↔ украинский, английский ↔ украинский.
- Направление угадывается по буквам текста и вашему прошлому выбору — обычно достаточно нажать «OK».
- **Обратный перевод** результата одной кнопкой — удобно, чтобы проверить перевод.
- Запуск из меню приложений открывает окно для ввода текста вручную.

## Установка

1. Скачайте `translateer_<версия>_all.deb` со страницы [Releases](https://github.com/anrysys/translateer/releases/latest).
2. Откройте файл двойным щелчком — откроется App Center — и нажмите «Установить».

Или в терминале:

```bash
sudo apt install ./translateer_1.0.0_all.deb
```

Зависимости (`translate-shell`, `wl-clipboard`, `zenity`, `libnotify-bin`) установятся автоматически.

## Использование

1. Запустите **Translateer** из меню приложений. При первом запуске программа назначит горячую клавишу **Ctrl+Alt+E**, если это сочетание свободно, и откроет окно для ввода текста.
2. Дальше выделяйте текст в любой программе и нажимайте **Ctrl+Alt+E**. Если ничего не выделено, переводится содержимое буфера обмена.
3. Выберите направление перевода и нажмите «OK».
4. В окне с переводом:
   - **⇄ Обратный перевод** — перевести результат обратно на исходный язык;
   - **Другое направление** — выбрать другое направление для того же текста;
   - **Закрыть**.

### Если Ctrl+Alt+E занято или у вас не GNOME

Назначьте любое сочетание вручную: **Настройки → Клавиатура → Комбинации клавиш → Особые комбинации → «+»**, команда — `translateer`. В других окружениях (KDE, Xfce и т. д.) — в их настройках клавиатуры.

## Требования

- Рабочий стол GNOME в сеансе Wayland. Проверено на Ubuntu 26.04.
- Подключение к интернету: перевод выполняет [translate-shell](https://github.com/soimort/translate-shell).

## Удаление

```bash
sudo apt remove translateer
```

Горячая клавиша останется в настройках — удалите её в **Настройки → Клавиатура → Комбинации клавиш → Особые комбинации**. Настройки программы хранятся в `~/.config/translateer/`.
