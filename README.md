<h1 align="center">Translateer</h1>

<p align="center">
  Перевод выделенного текста между русским, английским и украинским одним сочетанием клавиш.
</p>

## Возможности

- Выделите текст в любой программе и нажмите **Ctrl+Alt+E** — сразу появится перевод.
- Шесть направлений: русский ↔ английский, русский ↔ украинский, английский ↔ украинский.
- Направление спрашивается **один раз для каждого языка** текста и запоминается: например, русский — на английский, английский — на русский.
- **Ctrl+Alt+Shift+E** или кнопка **«Другое направление»** — выбрать другое направление, когда нужно.
- **Обратный перевод** результата одной кнопкой — удобно, чтобы проверить перевод.
- Окно перевода одно: новый перевод появляется в уже открытом окне, на том же месте и того же размера, и выходит поверх всех окон. Размер запоминается и после закрытия.
- Запуск из меню приложений открывает окно для ввода текста вручную.

## Установка

1. Скачайте `translateer_<версия>_all.deb` со страницы [Releases](https://github.com/anrysys/translateer/releases/latest).
2. Откройте файл двойным щелчком — откроется App Center — и нажмите «Установить».

Или в терминале, из папки со скачанным файлом:

```bash
sudo apt install ./translateer_*_all.deb
```

Зависимости (`translate-shell`, `wl-clipboard`, `zenity`, `libnotify-bin`, GTK 4 для Python) установятся автоматически.

## Использование

1. Запустите **Translateer** из меню приложений. При первом запуске программа назначит горячие клавиши (только если сочетания свободны) и откроет окно для ввода текста.
2. Выделите текст в любой программе и нажмите **Ctrl+Alt+E**. Если ничего не выделено, переводится содержимое буфера обмена.
3. Когда текст на этом языке встречается впервые, Translateer спросит, на какой язык его переводить. Дальше такой текст переводится сразу.
4. В окне с переводом:
   - **⇄ Обратный перевод** — перевести результат обратно на исходный язык;
   - **Другое направление** — выбрать другое направление; новый выбор запомнится;
   - **Закрыть** (или Esc).

Чтобы сразу перевести в другом направлении, нажмите **Ctrl+Alt+Shift+E**: сначала откроется выбор направления.

За один раз переводится до 2000 символов. Если выделено больше, Translateer переведёт начало и предупредит об этом.

### Если сочетания заняты или у вас не GNOME

Translateer не перезаписывает чужие сочетания клавиш и при первом запуске сообщит, какие из них не назначил. Назначьте свои: **Настройки → Клавиатура → Комбинации клавиш → Особые комбинации → «+»**:

| Команда | Что делает |
|---|---|
| `translateer` | перевести выделенный текст |
| `translateer --choose` | перевести, сначала выбрав направление |

В других окружениях (KDE, Xfce и т. д.) — в их настройках клавиатуры.

## Требования

- Рабочий стол GNOME в сеансе Wayland. Проверено на Ubuntu 26.04.
- Подключение к интернету: перевод выполняет [translate-shell](https://github.com/soimort/translate-shell).

## Удаление

```bash
sudo apt remove translateer
```

Горячие клавиши останутся в настройках — удалите их в **Настройки → Клавиатура → Комбинации клавиш → Особые комбинации**. Выбранные направления хранятся в `~/.config/translateer/targets`: удалите этот файл, чтобы Translateer снова спросил их.
